# primitive_db

Консольное приложение, имитирующее работу с примитивной базой данных:
таблицы с типизированными столбцами (`int`, `str`, `bool`), CRUD-операции,
хранение метаданных и данных в JSON.

## Установка и запуск

Требуется [uv](https://docs.astral.sh/uv/).

```
make install   # или: uv sync
make run       # или: uv run database
```

Установка как отдельной команды:

```
uv build
uv tool install dist/*.whl
database
```

Проверка кода: `make lint`.

## Управление таблицами

Команды:

- `create_table <имя> <столбец:тип> ...` — создать таблицу (типы: `int`, `str`, `bool`; столбец `ID:int` добавляется автоматически)
- `list_tables` — список таблиц
- `drop_table <имя>` — удалить таблицу
- `help` — справка
- `exit` — выход

Метаданные хранятся в `db_meta.json` в текущей директории.

Пример:

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
```

## CRUD-операции

Данные каждой таблицы хранятся в `data/<имя_таблицы>.json`. Строковые значения
пишутся в кавычках, булевы — `true`/`false`. Значение `ID` задавать не нужно:
оно генерируется автоматически.

- `insert into <таблица> values (<значение1>, <значение2>, ...)` — добавить запись
- `select from <таблица>` — показать все записи
- `select from <таблица> where <столбец> = <значение>` — записи по условию
- `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` — обновить записи
- `delete from <таблица> where <столбец> = <значение>` — удалить записи
- `info <таблица>` — столбцы и количество записей

Пример:

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок, подтверждения и кэш

Реализовано в [decorators.py](src/primitive_db/decorators.py):

- `handle_db_errors` — централизованная обработка ошибок (`FileNotFoundError`,
  `KeyError`, `ValueError`) во всех функциях `core.py`; вместо traceback
  выводится сообщение `Ошибка: ...`.
- `confirm_action` — перед `drop_table` и `delete` запрашивается подтверждение:

  ```
  >>>Введите команду: drop_table users
  Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
  Операция отменена.
  ```

- `log_time` — для `select` и `insert` выводится время выполнения:
  `Функция select выполнилась за 0.001 секунд.`
- `create_cacher` — замыкание-кэш для `select`: одинаковые запросы
  повторно не выполняются; кэш сбрасывается после `insert`, `update`,
  `delete` и `drop_table`.
